To specify a tax display preference for a partner:

1. Go to **Contacts** and open the partner.
2. In the sales section, set **Website Tax Display** to one of:

   - **Tax Excluded**
   - **Tax Included**

Leave the field empty to use the standard website tax display behavior.

For contacts linked to a company, the contact value takes precedence. If the
contact value is empty, the commercial entity value is used when set.
